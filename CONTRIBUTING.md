# Contributing to peNgo

Thank you for your interest in contributing to **peNgo – Smart Retail Command Center**!

## Development Workflow

1. **Fork or Clone the repository**
   ```bash
   git clone https://github.com/Deepakmittal03/Tech-Titansa.git
   cd Tech-Titansa
   ```

2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```

3. **Install Dependencies**
   ```bash
   npm install
   ```

4. **Verify TypeScript & Build**
   ```bash
   npm run build
   ```

5. **Commit Your Changes**
   Follow conventional commit standards:
   - `feat: add new retail report export`
   - `fix: resolve barcode duplicate check`
   - `docs: update setup documentation`

6. **Submit a Pull Request**
   Describe your changes clearly with test verification steps.
